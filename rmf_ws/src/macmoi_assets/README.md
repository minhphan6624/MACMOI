# macmoi_assets

This package stores the static lab assets for the AIML Lab deployment:

- robot nav map (`aiml_lab.yaml` / `aiml_lab.pgm`)
- RMF building map (`aiml-lab.building.yaml` / `aiml-lab.png`)
- generated RMF nav graph (`nav_graphs/0.yaml`)

It does not contain fleet configuration or bringup launch files.
