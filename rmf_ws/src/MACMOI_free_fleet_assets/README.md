# MACMOI Free Fleet Assets

This package stores the lab-specific deployment assets for the AIML Lab free_fleet setup:

- robot nav map (`aiml_lab.yaml` / `aiml_lab.pgm`)
- RMF building map (`aiml-lab.building.yaml` / `aiml-lab.png`)
- generated RMF nav graph (`nav_graphs/1.yaml`)
- fleet configuration YAMLs

It does not contain adapter code or shared utilities.
